# Πάροχοι AI και δοκιμές φυσικής συνομιλίας

Η εφαρμογή χρησιμοποιεί την ίδια γνώση και οδηγίες ανά κατάστημα για OpenAI και Mistral. Κάθε πάροχος υλοποιεί την αναγνώριση αιτήματος, την επιλογή προϊόντων, τη σύνθεση της απάντησης και έναν ξεχωριστό έλεγχο τεκμηρίωσης. Οι καθημερινές απαντήσεις γράφονται από το μοντέλο. Τα σταθερά κείμενα περιορίζονται στα όρια υγείας/σφαλμάτων και σε παλιούς planner-only test consumers.

## Ιδιωτική ρύθμιση

Στο ignored `.env` ή στο secret manager του backend χρειάζονται τα παρακάτω. Τα πραγματικά keys δεν μπαίνουν ποτέ στο chat, στον browser του πελάτη ή στο Git.

| Πάροχος | Secret | Μοντέλο για σταθερή δοκιμή |
|---|---|---|
| OpenAI | `OPENAI_API_KEY` | `OPENAI_MODEL=gpt-4.1-mini-2025-04-14` |
| Mistral | `MISTRAL_API_KEY` | `MISTRAL_MODEL=mistral-small-2603` |

Το OpenAI snapshot αντιστοιχεί στο GPT-4.1 mini που επέλεξε ο χρήστης. Η συγκεκριμένη έκδοση αποφεύγει αλλαγές ενός alias κατά τη διάρκεια του πειράματος. Η πρόσβαση των συγκεκριμένων λογαριασμών στα μοντέλα δεν έχει ακόμη επιβεβαιωθεί. Το Mistral adapter χρησιμοποιεί structured JSON και `reasoning_effort: none`. Κάθε ενεργό σκέλος του A/B/C χρειάζεται διαθέσιμο αντίστοιχο πάροχο· δεν γίνεται σιωπηλή αλλαγή παρόχου σε αποτυχία.

Το OpenAI project έχει δημιουργηθεί, αλλά οι προηγούμενοι έλεγχοι δεν έδειξαν ενεργό billing/key. Δεν έχει ρυθμιστεί Mistral API key. Η συνδρομή ChatGPT, το Render hosting και τα API usage είναι διαφορετικές χρεώσεις. Για OpenAI ακολουθήστε το `OPENAI-SETUP.md`. Για Mistral χρησιμοποιήστε τον εταιρικό λογαριασμό στο επίσημο [Console](https://console.mistral.ai/) και ολοκληρώστε οι ίδιοι την απαιτούμενη ρύθμιση λογαριασμού/billing πριν αποθηκεύσετε το key ιδιωτικά.

## Έλεγχοι

`pnpm run doctor` εμφανίζει μόνο παρουσία ρυθμίσεων, όχι secrets. Η παρουσία τους δεν αποδεικνύει επιτυχή σύνδεση ή εγκατάσταση.

Μετά την ενεργοποίηση του επιλεγμένου API, το `pnpm ai:smoke openai` ή `pnpm ai:smoke mistral` εκτελεί πραγματικές κλήσεις του συγκεκριμένου παρόχου με ένα σταθερό, συνθετικό ελληνικό μήνυμα. Αυτός ο έλεγχος έχει την κανονική χρέωση API. Δεν χρησιμοποιεί πραγματικό πελάτη, Shopify δεδομένα ή βάση. Ελέγχει το συμβόλαιο structured output και την πλήρη ροή απάντησης/επαλήθευσης, όχι τη συνολική ποιότητα των Ελληνικών ή την αύξηση πωλήσεων. Το `pnpm check` χρησιμοποιεί μόνο απομονωμένα τεστ με ελεγχόμενες αποκρίσεις και δεν κάνει κλήσεις επί πληρωμή.

Πριν το storefront απαιτούνται πραγματικοί ελληνικοί δοκιμαστικοί διάλογοι με εγκεκριμένο υλικό: budget, επιλογή παραλλαγής, αναφορά «το δεύτερο», άρνηση αγοράς, έλλειψη γνώσης, Greeklish και ερωτήσεις υγείας. Εξετάζουμε φυσικότητα, υποστήριξη κάθε ισχυρισμού, ταχύτητα και πραγματική κατανάλωση. Η ξεχωριστή επαλήθευση της απάντησης είναι πιθανοτική και δεν εγγυάται μηδενική επινόηση.

## Κόστος και πείραμα

Μια συνήθης αναζήτηση κάνει πλέον τέσσερις κλήσεις: δύο αποφάσεις, σύνθεση και επαλήθευση. Χαιρετισμός συνήθως τρεις· ένα αίτημα υγείας που αναγνωρίζεται τοπικά καμία. Οι κλήσεις έχουν όριο έξι δευτερολέπτων η καθεμία και ολόκληρη η δικτυακή ροή συνομιλίας όριο 25 δευτερολέπτων. Δεν γίνονται αυτόματες επαναλήψεις αποτυχημένων κλήσεων.

Το `model_usage` κρατά μόνο συγκεντρωτικά tokens, πλήθος κλήσεων, επιτυχίες, χρόνους και εκδόσεις. Απουσία token usage καταγράφεται ως άγνωστη χρήση, ποτέ ως μηδενική χρέωση. Τα όρια συνομιλιών δεν είναι σκληρό όριο χρημάτων. Οι προηγούμενες εκτιμήσεις κόστους με δύο κλήσεις χρειάζονται νέα πραγματική μέτρηση.

Το Nutri Tiger έχει προετοιμασμένο αλλά **ανενεργό** πείραμα 33% OpenAI / 33% Mistral / 34% control. Ενεργοποιείται μόνο μετά από επιτυχή έλεγχο και των δύο παρόχων, της εγκεκριμένης γνώσης και της σύνδεσης πειράματος–checkout σε unpublished preview. Αλλαγή μοντέλου, γνώσης, οδηγιών ή βαρών απαιτεί νέο experiment ID. Το report μετρά consented επισκέπτες και παρατηρημένη ολοκλήρωση checkout, όχι εξοφλημένες παραγγελίες ή καθαρό κέρδος. Οι αναφορές είναι περιγραφικές· δεν περιέχουν ακόμη στατιστική απόφαση νικητή ή αυτόματο υπολογισμό ROI.
